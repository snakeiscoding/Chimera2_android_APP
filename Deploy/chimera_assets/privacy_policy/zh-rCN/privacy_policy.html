隐私政策
上次更新日期：2019/10/18
本隐私政策适用于乔山健康科技有限公司及其关联方、子公司、分公司和品牌（统称“Matrix”、“Johnson”、“Johnson Fitness”、“本公司”或“我们”）通过其位于www.matrixfitness.com 的网站、其运动产品控制台上的应用程序、数码产品、其移动应用程序以及本公司为我们第三方业务伙伴提供支持且载有或公布有本隐私政策的网站和移动应用程序提供之所有产品和服务（统称“Matrix On-Console 服务”）使用 Matrix On-Console 服务之前，请仔细阅读本隐私政策。

如果您对我们的隐私惯例存在任何疑问，请参阅下文标题为“联系我们”章节所示方式联系我们。

1.我们收集的信息

我们收集信息主要是为了提供和改进 Matrix On-Console 服务，管理您对 Matrix On-Console 服务的使用情况（如果您是帐户持有者，则包括您的帐户），以及让您享受并轻松浏览 Matrix On-Console 服务。我们还因本隐私政策所述之其他用途收集信息。以下列出了我们收集的一些信息类型示例及其来源：
A. 您提供的信息

  • 帐户创建。您可以不注册的情况下使用 Matrix On-Console 服务的某些功能。您在注册控制台上的帐户或注册其他需要注册的 Matrix On-Console Service 时，我们会要求您提供一些信息，包括您的个人可识别信息（可用于识别您身份的信息，比如您的姓名和电子邮件地址）。作为注册流程的一部分，我们还会收集密码、密码提示以及帐户访问和验证所需的其他信息。如果您选择通过您的某个第三方服务（比如 Facebook 或 Twitter）帐户（单独称为社交网络服务或“SNS 帐户”）创建帐户，您须向我们提供您的用户名（或用户 ID），以便 SNS 帐户对您的身份进行验证。完成验证后，我们可以将您的帐户与 SNS 帐户绑定，并访问某些信息，比如您的姓名和电子邮件地址，以及 SNS 帐户上您的隐私设置允许我们访问的其他信息。  

 

  • 个人档案信息。您可以选择提供其他信息来补充您的个人资料，其中包括个人识别信息、电话号码或用于个人档案的照片和个人简介，但这些信息并非必填项。  

 

  • 您的健身活动。我们可能会收集与您的健身活动和身体特征有关的信息，比如您办卡的俱乐部、健身会员号、性别、出生日期、身高、体重、教练姓名、运动计划、锻炼数据（比如锻炼时长和强度、锻炼时间、所用器材、消耗的卡路里、距离、平均速度）。这些收集的信息可能是您手动添加的，也可能是从与您帐户关联的其他第三方服务处收到的。我们可能还会保存与您身体状况、身体尺寸、身高体重指数有关的信息，以及您向健身房的教练提供的其他信息。 

 

  • 通讯。我们会收集您向我们或教练发送的消息内容，比如反馈、问题，以及您向客户支持人员提供的信息。 

您可以选择通过 Matrix On-Console 服务主动向我们提交我们未要求提供的其他信息，在这种情况下，您对该等信息全权负责。


B. 自动收集的信息
我们自动收集与您的设备以及您的设备与 Matrix On-Console 服务互动方式有关的信息。我们收集的一些信息示例包括服务使用数据（比如您使用的 Matrix On-Console 服务或电子产品的功能、您在控制台上访问的页面、与用户 ID 对应的已执行锻炼、浏览时间、进入和退出的页面）、设备连接情况和配置数据（比如所用浏览器或设备的类型、设备的操作软件、网络服务提供商、设备的区域和语言设置以及诸如 IP 地址、MAC 地址和设备广告 ID 等设备识别码）以及位置数据（比如维度/经度数据或从 IP 地址衍生的位置或表示城市或邮编代码的数据）。
我们使用各种现行技术和稍后开发的技术来收集此信息，包括：

  • 日志信息。 您访问 Matrix On-Console 服务时，训练期间产生的信息将被自动记录并保存在我们的服务器上。 

  • Cookie。 我们通过使用 cookie 收集某些信息，cookie 是您在访问 Matrix On-Console 服务时浏览器保存的小型文本文件。我们可使用会话 cookie 和永久性 cookie 来确定您已登录 Matrix On-Console 服务，并了解您与 Matrix On-Console 服务互动的方式和时间。我们可以使用 cookie 来监控 Matrix 主控台服务上的总体使用情况和网路流量路由，以及定制和改进 Matrix 主控台服务。此外，cookie 允许我们在登录和注销 Matrix On-Console 服务时向您展示广告。与永久性 cookie 不同，在您注销 Matrix On-Console 服务并关闭浏览器时，会话 cookie 会被删除。某些第三方服务提供商可能还会将他们自己的 cookie 存储在您的浏览器上。注意，本隐私政策仅涵盖我们对 cookie 的使用，并不涉及该等第三方对 cookie 的使用。 

C. 来自其他来源的信息
我们还从其他第三方来源获取您的相关信息。如果我们将该等第三方提供的信息与我们通过 Matrix On-Console 服务收集的与您有关的信息进行合并，我们会根据本隐私政策所述的惯例，以及该等数据来源规定的任何其他限制来处理该等合并信息。该等第三方来源会随时间发生变化，但包括：

  • 与您的活动关联的健身器材。 

  • 与您的用户帐户相关的锻炼。 

  • 与我们提供联合品牌服务、销售或经销产品或参与联合营销活动的合作伙伴。 


如需有关第三方服务的其他信息，请参阅下文标题为“第三方”的章节。

2.信息使用
本公司按照本隐私政策规定的用途处理您的信息。除了本隐私政策其他地方规定的用途外，本公司还会为了我们的合法利益使用您的相关信息，包括：

  • 管理 Matrix On-Console 服务，包括您的注册情况和帐户； 

  • 执行您要求的服务，比如回复您的评论、问题和要求，并提供客户服务； 

  • 确保 Matrix On-Console 服务在技术上运行正常； 

  • 向您发送技术通知、更新、安全提醒、与我们的政策变更有关的信息以及支持和管理信息； 

  • 保护本公司、第三方或我们用户的权利和财产； 

  • 防止和处理欺诈、违反政策或条款的行为、威胁或伤害事件； 

  • 进行审计、研究和分析，以便维护、保护和改进 Matrix On-Console 服务、其他公司产品、营销活动、服务和运动器材的使用；以及 

  • 开发新服务。 

在征得您同意后，我们还将您的信息用于以下用途：

  • 开发和展示定制的内容和广告； 

  • 在 Matrix On-Console 服务和第三方服务上投放您感兴趣的广告；以及 

  • 满足向您披露之任何其他用途并征得您的同意。 

我们可能会使用不能识别您身份的信息（包括去身份识别化的信息），而无需对您承担任何义务，适用法律禁止的情况除外。就我们如何使用您的信息，如需了解您的相关权利和选择，请参阅下文标题为“您的权利和选择”的章节。

3.信息共享
本公司在如下所述情况下共享您的信息：

  • 与俱乐部和教练共享。我们会与办卡俱乐部（您锻炼所在的地方）和您指定的教练（陪伴您锻炼的人）共享您的信息，包括您的名字、电子邮件地址、Matrix On-Console 服务帐户 ID 和锻炼数据（比如锻炼时长和强度、锻炼时间、所用器材、消耗的卡路里、距离、平均速度）。我们作为俱乐部和教练的信息处理者，为了方便处理您的请求，我们还会共享您的信息，但必须遵守适用法律。 

  • 与关联方共享。我们与我们的关联实体（包括我们的母公司和姐妹公司）共享您的信息。例如，我们可能会与我们的关联方共享您的信息，以便提供客户支持，进行营销或技术操作。 

  • 与第三方共享。为了加快处理您的请求，我们会与第三方共享您的信息。例如，如果您选择将 Matrix On-Console 服务帐户用于其他第三方和社交网站，并希望向这些第三方网站提供您的公共信息，则您可以要求我们通过 Matrix On-Console 服务进行该等操作。  

  • 用于合并或收购。如果本公司涉足合并、收购或以任何形式出售其全部或部分资产，您的信息会随该等交易进行转让，在这种情况下，我们会尽职商业上的合理努力，确保对该等交易中涉及的任何信息保密，并在您的个人信息受到其他隐私政策的约束时，通知您。 

  • 安全或强制性披露。如果我们有充分理由相信，基于以下因素，访问、使用、保存或披露该等信息是合理必要的，则我们会共享您的信息：(a) 符合任何适用法律、法规、法律程序或具有法律效力的政府要求，(b) 强制执行《服务条款》，包括对可能违反《服务条款》的情况开展调查，(c) 检测、防止或以其他方式解决欺诈、安全或技术问题，或 (d) 根据法律规定或在法律允许的范围内，保护本公司、其用户或大众的权利、财产或安全。我们会共享您的信息，来满足政府机构的合法要求，包括满足国家安全或执法要求。 

  • 征得同意。出于向您披露的任何其他用途以及在征得您同意的情况下，我们会共享您的信息。 

在不限制前述规定的前提下，例如出于行业分析、人口统计和其他类似研究和营销等用途，我们会与第三方共享无法识别您的某些合并信息，比如锻炼时长和强度。如需了解与您的信息管理或使用有关的任何其他问题，请通过下文标题为“联系我们”章节所列方式联系我们。

4.第三方

A. 第三方服务
Matrix On-Console 服务可能包含其他网站和服务的链接。您在第三方网站或服务（包括但不限于 fitbit.com 或 mapmyfitness.com）提供的或向该等网站或服务提供的任何信息会直接提供给该等网站或服务的所有者，并受该方隐私政策的约束。我们的隐私政策不适用于该等网站或服务，且我们不对该等网站或服务的内容、隐私或安全惯例和政策负责。为了保护您的信息，我们建议您在访问其他网站和服务时仔细查阅其隐私政策。

Google Analytics
Google Analytics 是 Google Inc.（地址为 1600 Amphitheatre Parkway, Mountain View, CA 94043, USA，简称 "Google"）提供的一项服务。本公司在 Matrix On-Console 服务的各个平台上使用 Google Analytics 功能“用户 Id”来收集与您在本地和全球范围内使用我们服务有关的信息，以改进和帮助我们分析 Matrix On-Console 服务。我们的网站也使用 Google Analytics 来监控流量和用户体验，但我们不会通过这种方式来收集可识别个人身份的信息。在 Matrix On-Console 服务的注册和使用过程中，我们会收集与控制台上功能和应用程序的使用情况有关的数据。这些数据包含：锻炼时所用的应用程序、训练时长、搜索历史和锻炼统计数据以及与应用程序使用情况有关的综合数据。标识关键字可让人们识别应用程序上的用户个人，但该关键字经过匿名化处理，无法与任何用户的个人可识别信息关联。我们不会保存或处理用户的登录信息。对应用程序使用情况的结果分析有助于我们改进服务，开发新功能，优化我们所注重的用户需求。  如需有关 Google Analytics 数据保护政策的更多信息，请参阅 https://policies.google.com/privacy

5.您的权利和选择

A. 访问和删除帐户信息

您在使用 Matrix On-Console 服务时，我们会作出合理真诚努力，让您访问您通过帐户向我们提交的信息，或者如果该等信息不准确，则对其进行更正，或者如果该等信息并非法律要求保留的信息或并非出于合法商业用途要求保留的信息，则会根据您的要求删除信息。如您想更正或删除您的信息，请按照下文标题为“联系我们”章节所示方式，向我们发送电子邮件，随时告知我们。我们会要求您提供其他信息，以便我们确定您的身份。请注意，为了遵守我们的法律义务、解决纠纷以及执行我们的协议，我们会在必要时保留并使用您的信息。加利福尼亚州居民和欧洲的数据主体拥有下文标题为“您的加利福尼亚州隐私权利”和“您的欧洲隐私权利”的章节规定的其他权利。 
您可以通过帐户设置或按照下文标题为“联系我们”的章节所示方式向我们发送电子邮件，永久删除您的帐户。我们会尽快采取措施删除您的信息，但为了备案或在法律另有规定的情况下，我们会对某些信息进行归档/备份。请注意，我们只能在 Matrix On-Console 服务中删除您的信息。本公司无法删除您与我们的第三方伙伴或网站共享的信息。因此，您取消订阅之后，此信息仍会保留在该等第三方网站和服务上。然而，在收到删除请求后，对于之前从本公司接收您数据进行处理的第三方伙伴，本公司会向其发送删除请求。

B. 您的加利福尼亚州隐私权利
加利福尼亚州的《反客户信息披露法》允许加利福尼亚州客户索取某些详细信息，以了解其某些类型的信息与第三方和（在某些情况下）关联方的共享方式，以及该等第三方和关联方如何用于直接营销用途。根据法律规定，企业应根据加利福尼亚州客户的请求向其提供某些信息，或允许加利福尼亚州客户选择接受或拒绝该等共享。
如果您是加利福尼亚州居民，且希望获得与我们遵守本法有关的信息，请按照下文标题为“联系我们”的章节所示方式联系我们。请求必须在描述部分第一行中包含“加利福尼亚州隐私权利请求”，并包含您的姓名、街道地址、城市、州和邮政编码。请注意，对于通过指定电子邮件地址或邮寄地址以外的方式提出的请求，本公司无需作出答复。

C. 您的欧洲隐私权利
如果您是欧洲的数据主体，您有权访问、纠正或删除我们通过 Matrix On-Console Service 收集的与您有关的任何个人数据。您还拥有数据可携权、被遗忘权以及限制或反对我们处理通过 Matrix On-Console Service 收集的您个人数据的权利。此外，您有权要求我们不得出于营销用途或与最初的个人数据收集用途或您之后授权的个人数据收集用途完全不同的用途来处理您的个人数据（或将其提供给第三方进行处理）。对于我们在征得您同意后进行的任何数据处理，您可随时撤销该等同意。只需按照下文标题为“联系我们”章节所示方式联系我们。
如对我们的合规行为存在任何疑问，您有权向欧洲监管部门投诉。 

6.信息安全
我们采取合理恰当的安全措施，以防我们从您那里收集的或收集的与您有关的信息遭到未经授权的访问、使用、篡改、披露或毁坏。在用户明确要求删除其存储在我们服务器上的帐户数据之前，或在处理该等数据的法律依据失效之前，我们会保留该等数据。但请注意，任何通过网络传输信息或存储信息的方式都不是绝对安全的。因此，我们无法保证任何信息的绝对安全。

7.跨境传输

我们公司总部位于美国，我们收集的信息受美国法律的管辖。您的信息可能会被传输到位于您所在州、省、国家或其他政府管辖范围以外的计算机上并在其上进行维护，这些地区的隐私保护法可能与您所在司法辖区的隐私保护法不同。如果您位于美国以外地区，并选择向我们提供信息，我们会将该等信息传输至美国和其他司法管辖区并在那里处理。您使用 Matrix On-Console Service 或提供任何信息，即表示您同意该等传输和处理。如果您的数据是在欧洲收集的，我们会根据适当的或合适的保障措施（比如标准合同条款）对您的个人数据进行传输。 


8.我们针对儿童的政策
Matrix On-Console 服务不会发送给 13 岁以下的人士，且我们不会在知情的情况下向 13 岁以下儿童收集《美国儿童在线隐私保护法》("COPPA”) 定义的个人信息。如果我们得知，我们收集了 13 岁以下儿童的个人信息，我们会采取措施，尽快从我们的文件中删除该等信息。

9.本隐私政策的变更

请注意，我们会不时更改本隐私政策，您应定期查看。任何变更将在隐私政策修订版公布后即刻生效。您继续使用我们的服务，即表示您同意当时公布的隐私政策。如果变更内容非常重要，我们可能会另行发送电子邮件通知您。

10.数据控制者

欧盟数据保护法对为其自身用途处理个人数据的组织（称为“控制者”）与代表其他组织处理个人数据的组织（称为“处理者”）进行了区分。根据情况，本公司既可作为您个人数据的控制者，也可作为处理者。本公司（地址如下文标题为“联系我们”章节所示）是您通过 Matrix On-Console 服务输入信息的控制者。此信息包括单点登录凭证、Asset Management 用户信息和其他服务。

本公司（地址如下文标题为“联系我们”的章节所示）是通过健身器材产生之任何运动信息的处理者。  购买 Matrix On-Console 服务供其终端用户体验的客户为数据控制者。  在此情况下，本公司为数据处理者，代表客户的意愿对用户数据进行处理。

有时候，本公司代表作为独立法律实体的客户（控制者）进行数据处理。例如，本公司为俱乐部和教练提供技术，以便他们向您提供他们自有的应用程序以及进行健身追踪。

在此类情况下，本公司代表其客户并根据其要求处理个人数据。请查阅相关客户的隐私政策，了解他们的隐私惯例。如对该等个人数据以及您在数据保护法项下的权利存在任何疑问，应联系作为数据控制者的客户，而不是本公司。.
