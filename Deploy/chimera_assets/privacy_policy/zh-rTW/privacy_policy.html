若對我們的隱私權實踐存在任何疑問，請參閱下文中標題為「聯絡我們」的章節聯絡我們。

1.我們蒐集的資訊

我們蒐集資訊的主要目標是提供和改進 Matrix On-Console 服務，管理您對 Matrix On-Console 服務的使用情況（若您是帳戶持有者，則包括您的帳戶），以及讓您享用並輕鬆導覽 Matrix On-Console 服務。我們還因本隱私權政策所述之其他用途蒐集資訊。下面列示了我們蒐集的一些資訊類型範例及其來源：
A. 您提供的資訊

  • 帳戶建立。您可以在不註冊的情況下使用 Matrix On-Console 服務的某些功能。您在註冊儀表帳戶或其他需要註冊的 Matrix On-Console 服務時，我們會要求您提供一些資訊，包括您的個人可識別資訊（可用於識別您身分的資訊，例如您的姓名和電子郵件地址）。作為註冊程序的一部分，我們還會蒐集密碼、密碼提示以及帳戶存取和驗證所需的其他資訊。若您選擇透過您的某個第三方服務（如 Facebook 或 Twitter）帳戶（單獨稱為社交網路服務或「SNS 帳戶」）建立帳戶，您可能需要向我們提供您的使用者名稱（或使用者 ID），以便 SNS 帳戶對您的身分進行驗證。完成驗證後，我們可以將您的帳戶與 SNS 帳戶關聯，並存取某些資訊，例如您的姓名和電子郵件地址，以及 SNS 帳戶上您的隱私權設定允許我們存取的其他資訊。  

 

  • 個人檔案資訊。您可以選擇提供其他資訊來補充您的個人檔案，其中包括個人識別資訊、電話號碼，或用於個人檔案的相片以及個人簡介，但這些資訊並非必填項。  

 

  • 您的健身活動。我們可能會蒐集與您的健身活動和身體特徵有關的資訊，例如您辦卡的俱樂部、健身會員 ID、性別、出生日期、身高、體重、教練姓名、運動時間表、運動資料（例如運動時長和強度、運動時間、所用器材、已消耗卡路里、距離、平均速度）。蒐集的該資訊可能是您手動新增，也可能是從與您帳戶關聯的其他第三方服務處接收。我們可能還會儲存與您身體狀況、測量結果、身高體重指數 (BMI) 有關的資訊，以及您向健身房教練提供的其他資訊。 

 

  • 通訊。我們會蒐集您向我們或教練傳送的訊息內容，例如意見回饋、問題，以及您向客戶支援人員提供的資訊。 

您可以選擇透過 Matrix On-Console 服務主動向我們提交我們未要求提供的其他資訊，在這種情況下，您對該等資訊全權負責。


B. 自動蒐集的資訊
我們自動蒐集與您的裝置以及您的裝置與 Matrix On-Console 服務互動方式有關的資訊。我們蒐集的一些資訊範例包括服務使用資料（例如您使用的 Matrix On-Console 服務或數位產品的功能、您在儀表上造訪的頁面、與使用者 ID 關聯的已執行運動、瀏覽時間、進入和退出的頁面）、裝置連線情況和組態資料（例如裝置類型或所用瀏覽器、裝置的操作軟體、網路服務提供者、裝置的區域和語言設定以及諸如 IP 位址、MAC 位址和裝置廣告 ID 等裝置識別碼）以及位置資料（例如維度/經度資料或從 IP 位址衍生的位置或表示城市或郵遞區號的資料）。
我們使用各種現行技術和日後開發的技術來蒐集此資訊，包括：

  • 日誌資訊。 您存取 Matrix On-Console 服務時，訓練期間產生的資訊將被自動記錄並儲存在我們的伺服器上。 

  • Cookie。 我們透過使用「Cookie」蒐集某些資訊，這是在您存取 Matrix On-Console 服務時瀏覽器儲存的小型文字檔案。我們可使用工作階段 Cookie 和永久性 Cookie 來確定您已登入 Matrix On-Console 服務，並瞭解您與 Matrix On-Console 服務互動的方式和時間。我們還可使用 Cookie 來監控 Matrix On-Console 服務上的總體使用情況和網路流量路由，以及定製並改進 Matrix On-Console 服務。此外，Cookie 允許我們在登入和登出 Matrix On-Console 服務時向您展示廣告。與永久性 Cookie 不同，在您登出 Matrix On-Console 服務並關閉瀏覽器時，工作階段 Cookie 會被刪除。某些第三方服務提供者可能還會將他們自己的 Cookie 儲存在您的瀏覽器上。注意，本隱私權政策僅涵蓋我們對 Cookie 的使用，並不涉及該等第三方對 Cookie 的使用。 

C. 其他來源的資訊
我們還從其他第三方來源獲取您的相關資訊。若我們將該等第三方提供的資訊與我們透過 Matrix On-Console 服務蒐集的與您有關的資訊進行合併，我們會依據本隱私權政策所述的做法，以及該等資料來源規定的任何其他限制來處理該等合併資訊。該等第三方來源會隨時間發生變化，但包括：

  • 與您的活動關聯的健身器材。 

  • 與您的使用者帳戶相連接的運動。 

  • 我們與之提供聯合品牌服務、銷售或經銷產品或參與聯合行銷活動的合作夥伴。 


如需有關第三方服務的更多資訊，請參閱下文標題為「第三方」的章節。

  • 管理 Matrix On-Console 服務，包括您的註冊和帳戶； 

  • 執行您請求的服務，例如回應您的評論、問題和請求，並提供客戶服務； 

  • 確保 Matrix On-Console 服務在技術上運作正常； 

  • 向您傳送技術聲明、更新、安全提醒、與我們的政策變更有關的資訊以及支援和管理訊息； 

  • 保護本公司、第三方或我們使用者的權利和財產； 

  • 防止和處理詐騙、違反政策或條款的行為、威脅或傷害事件； 

  • 進行稽核、研究和分析，以便維護、保護和改進 Matrix On-Console 服務、其他公司產品、行銷活動、服務和運動器材的使用；以及 

  • 開發新服務。 

在徵得您同意後，我們還將您的資訊用於以下用途：

  • 開發和展示定製的內容和廣告； 

  • 在 Matrix On-Console 服務和第三方服務上投放您感興趣的廣告；以及 

  • 滿足向您揭露之任何其他用途並徵得您的同意。 

我們可能會使用不識別您身分的資訊（包括去身分識別化的資訊），而無需對您承擔任何義務，適用法律禁止的情況除外。就我們如何使用您的資訊，如需瞭解您的相關權利和選擇，請參閱下文標題為「您的權利和選擇」的章節。

3.資訊共用
本公司在如下所述情況下共用您的資訊：

  • 與俱樂部和教練共用。我們會與辦卡俱樂部（您運動所在的地方）和您指定的教練（陪伴您運動的人）共用您的資訊，包括您的姓名、電子郵件地址、Matrix On-Console 服務帳戶 ID 和運動資料（例如運動時長和強度、運動時間、所用器材、已消耗卡路里、距離、平均速度）。如果我們作為俱樂部和教練客戶的資料處理者，為了方便處理您的請求和遵循適用法律，我們還會共用您的資訊。 

  • 與關係企業共用。我們與我們的關聯實體（包括我們的母公司和姐妹公司）共用您的資訊。例如，我們可能與我們的關係企業共用您的資訊，以便提供客戶支援、進行行銷或技術操作。 

  • 與第三方共用。為了加快處理您的請求，我們會與第三方共用您的資訊。例如，若您選擇將 Matrix On-Console 服務帳戶用於其他第三方和社交網站，並希望向這些第三方網站提供您的公共資訊，則您可以請求我們透過 Matrix On-Console 服務進行該等操作。  

  • 用於合併或收購。若本公司涉足合併、收購或以任何形式出售其全部或部分資產，您的資訊會隨該等交易進行轉移，在這種情況下，我們會盡商業上的合理努力，確保對該等交易中涉及的任何資訊保密，並在您的個人資訊受到其他隱私權政策的約束時通知您。 

  • 安全或強制性揭露。若我們有充分理由相信，在下述情況下，存取、使用、保留或揭露該等資訊是合理必要的，則我們會共用您的資訊：(a) 符合任何適用法律、法規、法律程序或可強制執行的政府要求，(b) 強制執行《服務條款》，包括對可能違反《服務條款》的情況開展調查，(c) 偵測、防止或以其他方式解決詐騙、安全或技術問題，或 (d) 依據法律規定或在法律允許的範圍內，保護本公司、其使用者或大眾的權利、財產或安全。我們會共用您的資訊以滿足政府機構的合法要求，包括滿足國家安全或執法要求。 

  • 徵得同意。出於向您揭露的任何其他用途以及在徵得您同意的情況下，我們會共用您的資訊。 

在不限制前述規定的前提下，例如出於行業分析、人口統計和其他類似研究和行銷等用途，我們會與第三方共用無法識別您身分的某些合併資訊，例如運動時長和強度。如需瞭解與您的資訊管理或使用有關的任何其他問題，請透過下文標題為「聯絡我們」章節所列之方式與我們聯絡。

5.您的權利和選擇

A. 存取和刪除帳戶資訊

您在使用 Matrix On-Console 服務時，我們會作出合理真誠努力，讓您存取您透過帳戶向我們提交的資訊，或者若該等資訊不準確，則對其進行更正，或者若該等資訊並非法律要求保留的資訊或並非出於合法商業用途而保留的資訊，則會根據您的請求刪除資訊。若您想更正或刪除您的資訊，請按照下文標題為「聯絡我們」的章節所示方式，向我們傳送電子郵件，隨時告知我們。我們會要求您提供其他資訊，以便我們確定您的身分。請注意，為了遵守我們的法律義務、解決糾紛以及執行我們的協議，我們會在必要時保留並使用您的資訊。加州居民和歐洲的資料主體擁有下文標題為「您的加州隱私權」和「您的歐洲隱私權」章節規定的其他權利。 
您可以透過帳戶設定或按照下文標題為「聯絡我們」章節所示方式向我們傳送電子郵件，永久刪除您的帳戶。我們會儘快採取措施刪除您的資訊，但為了備案或在法律另有規定的情況下，我們會對某些資訊進行封存/備份。請注意，我們只能在 Matrix On-Console 服務中刪除您的資訊。本公司無法刪除您與我們的第三方夥伴及網站共用的資訊。因此，您取消訂閱之後，此資訊仍會保留在該等第三方網站和服務上。然而，在收到刪除請求後，對於之前從本公司接收您的資料進行處理的第三方夥伴，本公司會向其傳送刪除請求。

B. 您的加州隱私權
加州的《反客戶資訊揭露法》允許加州客戶索取某些詳細資訊，以瞭解如何與第三方和（在某些情況下）關係企業共用某些類型的資訊，以用於該等第三方和關係企業的直接行銷用途。依據法律規定，企業應根據加州客戶的請求向其提供某些資訊，或允許加州客戶選擇接受或拒絕此類共用。
若您是加州居民，且希望獲得與我們遵守該法律有關的資訊，請按照下文標題為「聯絡我們」章節所示方式與我們聯絡。請求必須在描述部分第一行中包含「加州隱私權請求」，並包含您的姓名、街道地址、城市、州和郵遞區號。請注意，對於透過指定電子郵件地址或郵寄地址以外的方式提出的請求，本公司無需作出答覆。

C. 您的歐洲隱私權
若您是歐洲的資料主體，您有權存取、更正或刪除我們透過 Matrix On-Console 服務蒐集的與您有關的任何個人資料。您還擁有資料可攜權、被遺忘權以及限制或反對我們處理透過 Matrix On-Console 服務蒐集的您個人資料的權利。此外，您有權要求我們不得出於行銷用途或與最初的個人資料蒐集或您之後授權的個人資料蒐集完全不同的用途來處理您的個人資料（或將其提供給第三方進行處理）。對於我們在徵得您同意後進行的任何資料處理，您可隨時撤銷該同意。只需按照下文標題為「聯絡我們」章節所示方式與我們聯絡。
若對我們的法規遵循行為存在任何疑問，您有權向歐洲監管部門投訴。

我們採取合理適當的安全措施，以防我們從您那裡蒐集的資訊或您的相關資訊遭到未經授權的存取、使用、篡改、揭露或損毀。在使用者明確請求刪除其儲存在我們伺服器上的帳戶資料之前，或在處理該等資料的法律依據失效之前，我們會保留該等資料。但請注意，任何透過網路傳輸資訊或儲存資訊的方式都不是絕對安全的。因此，我們無法保證任何資訊的絕對安全。

7.跨境傳輸
