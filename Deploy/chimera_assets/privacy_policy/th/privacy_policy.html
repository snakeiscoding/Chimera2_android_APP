นโยบายความเป็นส่วนตัวของ Johnson Health Tech - 10-17-2019

นโยบายความเป็นส่วนตัว
อัปเดตเมื่อ: 18/10/2019
นโยบายความเป็นส่วนตัวฉบับนี้มีผลกับผลิตภัณฑ์และบริการทั้งหมดที่เสนอโดย Johnson Health Tech Co., Ltd. และบริษัทในเครือ บริษัทสาขา แผนก และแบรนด์ของบริษัทฯ (ให้เรียกรวมกันว่า "Matrix," "Johnson," "Johnson Fitness," "บริษัท," "เรา,” และ "ของเรา" ) ผ่านเว็บไซต์ที่ www.matrixfitness.com, แอปพลิเคชันในแผงควบคุมของผลิตภัณฑ์ออกกำลังกาย, ผลิตภัณฑ์ดิจิทัล, แอปพลิเคชันในมือถือ และเว็บไซต์ รวมถึงแอปพลิเคชันในมือถือ ที่บริษัทจัดหาให้กับคู่ค้าทางธุรกิจภายนอก ที่มีนโยบายความเป็นส่วนตัวฉบับนี้หรือที่คุณอ่านนโยบายดังกล่าวได้ ("บริการใน Matrix On-Console") โปรดอ่านนโยบายความเป็นส่วนตัวฉบับนี้อย่างรอบคอบก่อนที่คุณจะใช่บริการใน Matrix On-Console

หากคุณมีคำถามใด ๆ เกี่ยวกับหลักปฏิบัติด้านความเป็นส่วนตัวของเรา โปรดติดต่อเราตามที่ระบุในหัวข้อ “ติดต่อเรา” ด้านล่าง

1. ข้อมูลที่เรารวบรวม

เป้าหมายหลักของเราในการรวบรวมข้อมูลคือเพื่อให้บริการและปรับปรุงบริการใน Matrix On-Console, เพื่อจัดการการใช้บริการใน Matrix On-Console (รวมถึงบัญชีของคุณ ถ้าคุณเป็นเจ้าของบัญชี) และเพื่อช่วยให้คุณเพลิดเพลินและใช้บริการใน Matrix On-Console ได้อย่างง่ายดาย เรายังรวบรวมข้อมูลเพื่อวัตถุประสงค์อื่นตามที่อธิบายไว้ในนโยบายความเป็นส่วนตัวฉบับนี้ด้วย ตัวอย่างบางส่วนของประเภทข้อมูลที่เรารวบรวมและสถานที่ที่เรารวบรวมข้อมูลมีดังต่อไปนี้:
ก. ข้อมูลที่คุณมอบให้

  • การสร้างบัญชี คุณอาจใช้บริการใน Matrix On-Console บางส่วนได้โดยไม่ต้องลงทะเบียน เมื่อคุณสมัครบัญชีในแผงควบคุมหรือบริการใน Matrix On-Console อื่น ๆ ที่ต้องมีการลงทะเบียน เราจะขอข้อมูลจากคุณ ซึ่งประกอบด้วยข้อมูลที่สามารถระบุตัวตนเกี่ยวกับคุณได้ (ข้อมูลที่สามารถใช้ระบุตัวตนของคุณได้ เช่น ชื่อและนามสกุล และที่อยู่อีเมลของคุณ) เรายังรวบรวมรหัสผ่าน คำใบ้รหัสผ่าน และข้อมูลอื่น ๆ สำหรับการยืนยันตัวตนและการเข้าสู่บัญชี ซึ่งเป็นส่วนหนึ่งของกระบวนการลงทะเบียนด้วย หากคุณเลือกสร้างบัญชีผ่านหนึ่งในบัญชีของคุณจากบริการภายนอกบางอย่าง เช่น Facebook หรือ Twitter (แต่ละอย่างคือบริการเครือข่ายโซเชียลหรือ "บัญชี SNS") คุณอาจต้องมอบชื่อผู้ใช้ (หรือ ID ผู้ใช้) ของคุณให้กับเรา เพื่อให้สามารถยืนยันตัวตนของคุณได้โดยใช้บัญชี SNS เมื่อยืนยันตัวตนของคุณเสร็จสมบูรณ์แล้ว เราจะสามารถเชื่อมโยงบัญชีของคุณกับบัญชี SNS ได้ และเข้าถึงข้อมูลบางอย่าง เช่น ชื่อและที่อยู่อีเมลของคุณ และข้อมูลอื่น ๆ ที่การตั้งค่าความเป็นส่วนตัวในบัญชี SNS อนุญาตให้เราเข้าถึง  

 

  • ข้อมูลโปรไฟล์ คุณมีตัวเลือกในการมอบข้อมูลเพิ่มเติม ซึ่งเป็นส่วนหนึ่งของโปรไฟล์ของคุณ ซึ่งบางส่วนเป็นข้อมูลที่ระบุตัวตนได้ หมายเลขโทรศัพท์ หรือภาพของโปรไฟล์ และคำอธิบายสั้น ๆ เกี่ยวกับตัวคุณเอง แต่ข้อมูลเหล่านี้ไม่ใช่ข้อมูลที่จำเป็นต้องระบุ  

 

  • กิจกรรมฟิตเนสของคุณ เราอาจรวบรวมข้อมูลเกี่ยวกับกิจกรรมฟิตเนสและลักษณะทางกายภาพของคุณ เช่น คลับหลัก, ID สมาชิกฟิตเนส, เพศ, วันเกิด, ส่วนสูง, น้ำหนัก, ชื่อของครูฝึก, ตารางการออกกำลังกาย, ข้อมูลการออกกำลังกาย (เช่น ระยะเวลาและความเข้มข้นของการออกกำลังกาย เวลาออกกำลังกาย อุปกรณ์ที่ใช้ แคลอรี่ที่เผาผลาญ ระยะทาง ความเร็วเฉลี่ย) คุณอาจเพิ่มข้อมูลที่เก็บรวบรวมนี้ได้ด้วยตนเองหรือเราอาจจะได้รับข้อมูลจากบริการภายนอกที่เชื่อมโยงกับบัญชีของคุณ เรายังอาจจัดเก็บข้อมูลเกี่ยวกับระดับสมรรถภาพร่างกาย การวัด ดัชนีมวลกาย และข้อมูลอื่น ๆ ที่คุณมอบให้แก่ครูฝึกในนามของสถาบันฟิตเนสของคุณด้วย 

 

  • การสื่อสาร เรารวบรวมเนื้อหาข้อความที่คุณส่งให้กับเราหรือครูฝึกของคุณ เช่น คำติชม คำถาม และข้อมูลที่คุณมอบให้แก่ฝ่ายสนับสนุนลูกค้า 

คุณอาจเลือกส่งข้อมูลอื่น ๆ ให้แก่เราโดยสมัครใจผ่านบริการใน Matrix On-Console ซึ่งเราไม่ได้ขอ และในกรณีดังกล่าว คุณก็เป็นผู้รับผิดชอบข้อมูลดังกล่าวแต่เพียงผู้เดียว


ข. ข้อมูลที่รวบรวมโดยอัตโนมัติ
เรารวบรวมข้อมูลเกี่ยวกับอุปกรณ์ของคุณและวิธีที่อุปกรณ์ของคุณโต้ตอบกับบริการในแผงควบคุม Matrix โดยอัตโนมัติ ตัวอย่างบางส่วนของข้อมูลที่เรารวบรวมได้แก่ข้อมูลการใช้บริการ (เช่น คุณสมบัติที่คุณใช้งานด้วยบริการใน Matrix On-Console และในผลิตภัณฑ์ดิจิทัล, หน้าเว็บที่คุณเยี่ยมชมผ่านแผงควบคุม, การออกกำลังกายของคุณที่ผูกเข้ากับ ID ผู้ใช้ของคุณ, เวลาของวันที่คุณเรียกดู และหน้าเว็บที่เชื่อมโยงและที่ออก), ข้อมูลการเชื่อมต่อและการกำหนดค่าของอุปกรณ์ (เช่น ประเภทอุปกรณ์และเบราว์เซอร์ที่คุณใช้, ระบบปฏิบัติการของอุปกรณ์, ผู้ให้บริการอินเทอร์เน็ตของคุณ, การตั้งค่าภูมิภาคและภาษาของอุปกรณ์, และตัวระบุของอุปกรณ์ของคุณ เช่น ที่อยู่ IP, ที่อยู่ MAC และ ID โฆษณาของอุปกรณ์) และข้อมูลตำแหน่งที่ตั้ง (เช่น ข้อมูลละติจูด/ลองจิจูด หรือตำแหน่งที่ตั้งที่ได้จากที่อยู่ IP หรือข้อมูลที่ระบุระดับเมืองหรือรหัสไปรษณีย์)
เราใช้เทคโนโลยีที่พัฒนาขึ้นทั้งในปัจจุบันและในภายภาคหน้า เพื่อรวบรวมข้อมูลนี้ รวมถึงเทคโนโลยีดังต่อไปนี้:

  • ข้อมูลบันทึก  เมื่อคุณเข้าถึงบริการใน Matrix On-Console ข้อมูลที่สร้างขึ้นระหว่างเซสชันของคุณจะได้รับการบันทึกและจัดเก็บในเซิร์ฟเวอร์ของเราโดยอัตโนมัติ 

  • คุกกี้  เรารวบรวมข้อมูลบางอย่างผ่านการใช้ “คุกกี้” ซึ่งก็คือไฟล์ข้อความขนาดเล็กที่เบราว์เซอร์บันทึกไว้เมื่อคุณเข้าถึงบริการใน Matrix On-Console เราอาจใช้ทั้งคุกกี้ชั่วคราว (session cookies) และคุกกี้ที่มีกำหนดอายุ (persistent cookies) เพื่อระบุว่าคุณเข้าสู่ระบบบริการใน Matrix On-Console และเพื่อแจ้งเราว่าคุณโต้ตอบกับบริการใน Matrix On-Console อย่างไรและเมื่อใด เรายังอาจใช้คุกกี้เพื่อติดตามการใช้งานแบบรวมและเส้นทางการรับส่งข้อมูลของเว็บบนบริการใน Matrix On-Console และเพื่อปรับแต่งและปรับปรุงบริการใน Matrix On-Console  อีกด้วย นอกจากนี้ คุกกี้ยังช่วยให้เรานำเสนอโฆษณาให้แก่คุณ ทั้งในและนอกบริการใน Matrix On-Console คุกกี้ชั่วคราวจะถูกลบไปเมื่อคุณออกจากระบบบริการใน Matrix On-Console และปิดเบราว์เซอร์ ซึ่งแตกต่างจากคุกกี้ที่มีกำหนดเวลา ผู้ให้บริการภายนอกบางส่วนอาจวางคุกกี้ของตนเองไว้ในเบราว์เซอร์ของคุณด้วย ทั้งนี้ โปรดทราบว่านโยบายความเป็นส่วนตัวฉบับนี้ครอบคลุมเฉพาะการใช้คุกกี้ของเรา และไม่รวมคุกกี้จากบุคคลภายนอกดังกล่าว 

ค. ข้อมูลจากแหล่งอื่น
เรายังรวบรวมข้อมูลเกี่ยวกับคุณจากแหล่งภายนอกอื่น ๆ ด้วย ภายในขอบเขตที่เรารวมข้อมูลที่ได้จากแหล่งภายนอกดังกล่าวเข้ากับข้อมูลที่เรารวบรวมเกี่ยวกับคุณผ่านบริการใน Matrix On-Console เราจะปฏิบัติต่อข้อมูลที่รวมนั้นตามหลักปฏิบัติที่อธิบายไว้ในนโยบายความเป็นส่วนตัวฉบับนี้ รวมถึงข้อจำกัดเพิ่มเติมใด ๆ ที่แหล่งที่มาของข้อมูลกำหนด แหล่งภายนอกเหล่านี้แตกต่างกันไปเมื่อเวลาผ่านไป แต่รวมถึง:

  • อุปกรณ์ฟิตเนสที่เชื่อมโยงกับกิจกรรมของคุณ 

  • การออกกำลังกายที่เชื่อมต่อกับบัญชีผู้ใช้ของคุณ 

  • พันธมิตรที่เราเสนอการให้บริการร่วมแบรนด์ การขายหรือจัดจำหน่ายผลิตภัณฑ์ของเรา หรือมีส่วนร่วมในกิจกรรมการตลาดร่วมกัน 


หากต้องการข้อมูลเพิ่มเติมเกี่ยวกับบริการภายนอก โปรดดูหัวข้อ “บุคคลภายนอก” ด้านล่าง

2. การใช้ข้อมูล
บริษัทประมวลผลข้อมูลของคุณเพื่อวัตถุประสงค์ตามที่อธิบายในนโยบายความเป็นส่วนตัวฉบับนี้ นอกจากวัตถุประสงค์ที่ระบุที่อื่นภายในนโยบายความเป็นส่วนตัวฉบับนี้แล้ว บริษัทยังใช้ข้อมูลเกี่ยวกับคุณสำหรับผลประโยชน์ที่ชอบด้วยกฎหมายของเรา รวมถึง:

  • การจัดการบริการใน Matrix On-Console รวมถึงการลงทะเบียนและบัญชีของคุณ 

  • การให้บริการที่คุณร้องขอ เช่น ตอบความคิดเห็น คำถาม และคำขอของคุณ และให้บริการลูกค้า 

  • การรับประกันการทำงานเชิงเทคนิคของบริการใน Matrix On-Console 

  • การส่งการแจ้งเตือนทางเทคนิค การอัปเดต การแจ้งเตือนด้านความปลอดภัย ข้อมูลเกี่ยวกับการเปลี่ยนแปลงนโยบาย และข้อความสนับสนุนและข้อความการดูแล 

  • การปกป้องสิทธิและทรัพย์สินของบริษัท บุคคลภายนอก หรือผู้ใช้ของเรา 

  • การป้องกันและจัดการกับการฉ้อโกง การละเมิดนโยบายหรือเงื่อนไข และภัยคุกคามหรืออันตราย 

  • การตรวจสอบ วิจัย และวิเคราะห์เพื่อรักษา ปกป้อง และปรับปรุงบริการใน Matrix On-Console ผลิตภัณฑ์ของบริษัทอื่น ๆ การทำตลาดและบริการ และการใช้อุปกรณ์ออกกำลังกาย และ 

  • การพัฒนาบริการใหม่ 

เรายังใช้ข้อมูลเกี่ยวกับคุณโดยที่ได้รับความยินยอมของคุณแล้ว เช่นเพื่อ:

  • พัฒนาและแสดงเนื้อหาและโฆษณาที่ปรับแต่ง 

  • แสดงโฆษณาที่เลือกสรรตามความสนใจของคุณในบริการใน Matrix On-Console และบริการภายนอกและ 

  • ปฏิบัติตามวัตถุประสงค์อื่นใดที่เปิดเผยให้คุณ และได้รับความยินยอมจากคุณ 

เราอาจใช้ข้อมูลที่ไม่ระบุตัวตนของคุณ (รวมถึง ข้อมูลที่ทำให้ไม่สามารถระบุตัวตนได้) โดยไม่มีข้อผูกพันกับคุณ ยกเว้นมีกฎหมายที่เกี่ยวข้องสั่งห้าม สำหรับข้อมูลเกี่ยวกับสิทธิและทางเลือกเกี่ยวกับวิธีที่เราใช้งานข้อมูลของคุณ โปรดดูหัวข้อ “สิทธิและทางเลือกของคุณ” ด้านล่าง

3. การแบ่งปันข้อมูล
บริษัทแบ่งปันข้อมูลคุณดังต่อไปนี้:

  • คลับและครูฝึก เราแบ่งปันข้อมูลของคุณ รวมถึงชื่อ, ที่อยู่อีเมล, ID บัญชีบริการใน Matrix On-Console และข้อมูลการออกกำลังกาย (เช่น ระยะเวลาและความเข้มข้นของการออกกำลังกาย เวลาออกกำลังกาย อุปกรณ์ที่ใช้ แคลอรี่ที่เผาผลาญ ระยะทาง ความเร็วเฉลี่ย) กับคลับหลัก (ที่ที่คุณออกกำลังกาย) และครูฝึก (คนที่คุณออกกำลังกายด้วย) ที่คุณได้กำหนดไว้ หากเรามีหน้าที่เป็นผู้ประมวลผลสำหรับคลับและลูกค้าครูฝึก เราก็จะแบ่งปันข้อมูลของคุณเพื่ออำนวยความสะดวกในการปฏิบัติตามคำขอของคุณ และเพื่อปฏิบัติตามกฎหมายที่ใช้บังคับด้วย 

  • บริษัทในเครือ เราแบ่งปันข้อมูลของคุณกับนิติบุคคลที่เกี่ยวข้อง รวมถึงบริษัทแม่และบริษัทในเครือ ตัวอย่างเช่น เราอาจแบ่งปันข้อมูลของคุณกับบริษัทในเครือเพื่อการสนับสนุนลูกค้า การตลาด และการดำเนินการทางเทคนิค 

  • บุคคลภายนอก เราแบ่งปันข้อมูลของคุณกับบุคคลภายนอกเพื่ออำนวยความสะดวกในการปฏิบัติตามคำขอของคุณ ตัวอย่างเช่น หากคุณเลือกเชื่อมโยงบัญชีของคุณในบริการใน Matrix On-Console เข้ากับเว็บไซต์ภายนอกและเว็บไซต์เครือข่ายโซเชียล และต้องการเปิดเผยข้อมูลสาธารณะของคุณในเว็บไซต์ภายนอก คุณอาจขอให้เราเปิดเผยข้อมูลได้ผ่านบริการใน Matrix On-Console  

  • การควบรวมหรือซื้อกิจการ หากบริษัทเข้าไปเกี่ยวข้องกับการควบรวมหรือการซื้อกิจการ หรือการขายสินทรัพย์บางส่วนหรือทั้งหมด ข้อมูลของคุณอาจถูกถ่ายโอน โดยเกี่ยวข้องกับธุรกรรมดังกล่าว ในกรณีดังกล่าว เราจะใช้ความพยายามอันสมเหตุสมผลทางการค้าเพื่อรักษาความลับของข้อมูลใด ๆ ที่เกี่ยวข้องในธุรกรรมดังกล่าว และแจ้งคุณเมื่อข้อมูลส่วนบุคคลของคุณอยู่ภายใต้นโยบายความเป็นส่วนตัวฉบับอื่น 

  • การรักษาความปลอดภัยหรือการเปิดเผยที่บังคับ เราแบ่งปันข้อมูลของคุณ หากเรามีความเชื่อโดยสุจริตใจว่าการเข้าถึง การใช้ การรักษา หรือการเปิดเผยข้อมูลดังกล่าวมีความจำเป็นที่สมเหตุสมผลเพื่อ (ก) ปฏิบัติตามกฎหมาย ระเบียบข้อบังคับ กระบวนการทางกฎหมาย หรือคำขอของรัฐที่มีผลบังคับใช้ (ข) บังคับใช้เงื่อนไขการบริการ รวมถึงการตรวจสอบการฝ่าฝืนใด ๆ ที่เป็นไปได้ (ค) ตรวจจับ ป้องกัน หรือจัดการกับการฉ้อโกง การรักษาความปลอดภัย หรือปัญหาทางเทคนิคโดยประการอื่นหรือ (ง) ป้องกันอันตรายต่อสิทธิ ทรัพย์สิน หรือความปลอดภัยของบริษัท ผู้ใช้ หรือสาธารณชน ตามที่กฎหมายกำหนดหรืออนุญาต เราแบ่งปันข้อมูลของคุณ เพื่อตอบสนองคำขอที่ชอบด้วยกฎหมายจากหน่วยงานสาธารณะ รวมถึงเพื่อปฏิบัติตามข้อกำหนดด้านการรักษาความปลอดภัยระดับประเทศหรือการบังคับใช้กฎหมาย 

  • ความยินยอม เราแบ่งปันข้อมูลของคุณสำหรับวัตถุประสงค์อื่นใดที่เปิดเผยต่อคุณ และเมื่อเรามีความยินยอมของคุณ 

ทั้งนี้ไม่มีข้อจำกัดของข้อความข้างต้น เราอาจแบ่งปันข้อมูลแบบรวมบางส่วน ซึ่งไม่ระบุตัวตนของคุณให้แก่บุคคลภายนอก เช่น ระยะเวลาและความเข้มข้นของการออกกำลังกาย ตัวอย่างเช่น เพื่อการวิเคราะห์อุตสาหกรรม การรวบรวมข้อมูลทางประชากรศาสตร์ และวัตถุประสงค์ด้านการวิจัยและการตลาดอื่นที่คล้ายกัน โปรดติดต่อเราตามช่องทางที่ระบุไว้ในหัวข้อ “ติดต่อเรา” ด้านล่าง หากมีคำถามเพิ่มเติมเกี่ยวกับการจัดการหรือการใช้ข้อมูลของคุณ

4. บุคคลภายนอก

ก. บริการภายนอก
บริการใน Matrix On-Console อาจมีลิงก์ที่เชื่อมโยงไปยังเว็บไซต์หรือบริการอื่น ข้อมูลใด ๆ ที่คุณมอบให้ในหรือมอบให้แก่เว็บไซต์หรือบริการภายนอก รวมถึงแต่ไม่จำกัดเพียง itbit.com หรือ mapmyfitness.com เป็นการมอบให้แก่เจ้าของของเว็บไซต์หรือบริการโดยตรง และอยู่ภายใต้นโยบายความเป็นส่วนตัวของบุคคลภายนอกนั้น นโยบายความเป็นส่วนตัวของเราไม่มีผลบังคับใช้กับเว็บไซต์หรือบริการดังกล่าว และเราไม่รับผิดชอบสำหรับเนื้อหา ความเป็นส่วนตัว หรือแนวปฏิบัติและนโยบายด้านการรักษาความปลอดภัยของเว็บไซต์หรือบริการเหล่านั้น เพื่อเป็นการคุ้มครองข้อมูลของคุณ เราแนะนำให้คุณตรวจสอบนโยบายความเป็นส่วนตัวของเว็บไซต์และบริการอื่นที่คุณเข้าถึงอย่างรอบคอบ

Google Analytics
Google Analytics คือบริการของ Google Inc. ซึ่งตั้งอยู่ที่ 1600 Amphitheatre Parkway, Mountain View, CA 94043, USA ("Google") บริษัทใช้ฟังก์ชันการทำงานของ Google Analytics ซึ่งก็คือ "ID ผู้ใช้" ผ่านทุกแพลตฟอร์มในบริการใน Matrix On-Console เพื่อรวบรวมข้อมูลเกี่ยวกับการที่คุณใช้บริการของเรา ทั้งในระดับท้องถิ่นและระดับโลก เพื่อปรับปรุงและช่วยเราวิเคราะห์บริการใน Matrix On-Console เว็บไซต์ของเราใช้ Google Analytics เพื่อตรวจติดตามการรับส่งข้อมูลและประสบการณ์ของผู้ใช้ แต่ไม่มีการรวบรวมข้อมูลที่ระบุตัวตนได้ในลักษณะนี้ ข้อมูลเกี่ยวกับการใช้ฟังก์ชันและแอปพลิเคชันในแผงควบคุมได้รับการรวบรวมผ่านการลงทะเบียนและการใช้บริการใน Matrix On-Console ซึ่งประกอบด้วยสิ่งต่าง ๆ ต่อไปนี้: แอปพลิเคชันที่ใช้ระหว่างการออกกำลังกาย ระหว่างการใช้งาน ประวัติการค้นหา และสถิติการออกกำลังกาย รวมถึงข้อมูลแบบรวมเกี่ยวกับการใช้แอปพลิเคชัน คีย์ประจำตัวช่วยให้ระบุตัวของผู้ใช้แต่ละคนได้ อย่างไรก็ตาม คีย์นี้ไม่มีการระบุตัวตน และไม่สามารถผูกกับข้อมูลที่ระบุตัวตนของผู้ใช้ได้ ข้อมูลเข้าสู่ระบบของผู้ใช้ไม่มีการจัดเก็บหรือประมวลผล ผลการวิเคราะห์เกี่ยวกับการใช้งานแอปพลิเคชันช่วยเราปรับปรุงบริการของเรา เพื่อพัฒนาคุณสมบัติใหม่ ๆ และเพื่อปรับปรุงความมุ่งเน้นของเราตามความต้องการของผู้ใช้ให้ดีที่สุด  สามารถดูข้อมูลเพิ่มเติมเกี่ยวกับนโยบายคุ้มครองข้อมูลของ Google Analytics ได้ที่ https://policies.google.com/privacy

5. สิทธิและทางเลือกของคุณ

ก. การเข้าถึงและลบข้อมูลบัญชี

เมื่อคุณใช้บริการใน Matrix On-Console เราจะใช้ความพยายามอันสุจริตใจที่สมเหตุสมผลเพื่อให้คุณเข้าถึงข้อมูลที่คุณส่งให้กับเราผ่านบัญชีของคุณ และเพื่อแก้ไขข้อมูลนี้หากไม่ถูกต้อง หรือเพื่อลบข้อมูลตามคำขอของคุณ หากไม่จำเป็นต้องเก็บรักษาไว้ตามกฎหมายโดยประการอื่นหรือเพื่อวัตถุประสงค์ทางธุรกิจที่ถูกต้องตามกฎหมาย โปรดอย่าลังเลที่จะแจ้งให้เราทราบ หากคุณต้องการแก้ไขหรือลบข้อมูลของคุณ โดยส่งอีเมลหาเราตามที่ระบุในหัวข้อ “ติดต่อเรา” ด้านล่าง เราอาจขอข้อมูลเพิ่มเติมจากคุณ เพื่อให้เราสามารถยืนยันตัวตนของคุณได้ โปรดทราบว่าเราจะเก็บรักษาและใช้งานข้อมูลของคุณตามที่จำเป็นเพื่อปฏิบัติตามข้อผูกพันทางกฎหมาย ระงับข้อพิพาท และบังคับใช้ข้อตกลงของเรา ผู้ที่พำนักอาศัยอยู๋ในรัฐแคลิฟอร์เนียและเจ้าของข้อมูลในยุโรปมีสิทธิเพิ่มเติมตามที่ระบุในหัวข้อ “สิทธิความเป็นส่วนตัวในแคลิฟอร์เนียของคุณ” และ “สิทธิความเป็นส่วนตัวในยุโรปของคุณ” ด้านล่าง 
เราสามารถลบบัญชีของคุณอย่างถาวรได้ผ่านการตั้งค่าบัญชี หรือโดยส่งอีเมลแจ้งเราตามที่ระบุในหัวข้อ “ติดต่อเรา” ด้านล่าง เราจะดำเนินการลบข้อมูลของคุณทันทีที่ทำได้ แต่ข้อมูลบางส่วนอาจยังคงอยู่ในสำเนาเก็บบันทึกถาวร/สำเนาสำรองข้อมูลสำหรับทะเบียนของเรา หรือตามที่กฎหมายกำหนด โปรดทราบว่าเราสามารถลบข้อมูลของคุณภายในบริการใน Matrix On-Console ได้เท่านั้น บริษัทไม่สามารถลบข้อมูลที่คุณแบ่งปันให้กับพันธมิตรและเว็บไซต์ภายนอกได้ ดังนั้น ข้อมูลนี้จะยังคงอยู่ในเว็บไซต์และบริการภายนอก แม้ว่าคุณยกเลิกการสมัครรับข้อมูลจากเราแล้ว อย่างไรก็ตาม เมื่อบริษัทได้รับคำขอให้ลบข้อมูล บริษัทจะส่งคำขอลบข้อมูลไปยังพันธมิตรภายนอกเหล่านั้นที่บริษัทเคยส่งข้อมูลของคุณไปประมวลผลก่อนหน้านี้ 

ข. สิทธิความเป็นส่วนตัวในแคลิฟอร์เนียของคุณ
กฎหมาย "Shine the Light" ของรัฐแคลิฟอร์เนียอนุญาตให้ลูกค้าในรัฐแคลิฟอร์เนียขอรายละเอียดบางอย่างเกี่ยวกับวิธีการแบ่งปันข้อมูลบางประเภทของตนกับบุคคลภายนอก และในบางกรณี ก็รวมถึงบริษัทในเครือ เพื่อวัตถุประสงค์ทางการตลาดโดยตรงของบุคคลภายนอกและบริษัทในเครือ ตามกฎหมายแล้ว ธุรกิจควรมอบข้อมูลบางอย่างให้กับลูกค้าชาวแคลิฟอร์เนียเมื่อมีการร้องขอ หรืออนุญาตให้ลูกค้าชาวแคลิฟอร์เนียเลือกรับหรือไม่รับการแบ่งปันประเภทนี้
หากคุณเป็นผู้ที่พำนักอาศัยอยู่ในรัฐแคลิฟอร์เนีย และต้องการขอข้อมูลเกี่ยวกับการปฏิบัติตามกฎหมายฉบับนี้ของเรา โปรดติดต่อเราตามที่ระบุในหัวข้อ “ติดต่อเรา” ด้านล่าง คำขอต้องระบุว่า “คำขอด้านสิทธิความเป็นส่วนตัวในแคลิฟอร์เนีย” ในบรรทัดแรกของคำอธิบายและระบุชื่อ ที่อยู่ เมือง รัฐ และรหัสไปรษณีย์ของคุณ โปรดทราบว่าบริษัทไม่จำเป็นต้องตอบสนองคำขอที่ส่งมาด้วยวิธีอื่นนอกจากที่อยู่อีเมลและที่อยู่ทางไปรษณีย์ที่ระบุ

ค. สิทธิความเป็นส่วนตัวในยุโรปของคุณ
หากคุณเป็นเจ้าของข้อมูลในยุโรป คุณมีสิทธิที่จะเข้าถึง แก้ไข หรือลบข้อมูลส่วนบุคคลใด ๆ ที่เรารวบรวมเกี่ยวกับคุณผ่านบริการใน Matrix On-Console คุณยังมีสิทธิในการโอนย้ายข้อมูล สิทธิที่จะถูกลืม และสิทธิที่จะจำกัดหรือคัดค้านการประมวลผลข้อมูลส่วนบุคคลที่เรารวบรวมเกี่ยวคุณผ่านบริการใน Matrix On-Console นอกจากนี้ คุณมีสิทธิที่จะขอไม่ให้เราประมวลผลข้อมูลส่วนบุคคลของคุณ (หรือมอบให้แก่บุคคลภายนอกเพื่อประมวลผล) เพื่อวัตถุประสงค์ทางการตลาด หรือวัตถุประสงค์ที่แตกต่างจากวัตถุประสงค์เดิมหรือที่คุณให้อนุญาตอย่างมีนัยสำคัญ คุณอาจเพิกถอนความยินยอมสำหรับการประมวลผลข้อมูลที่เราอาศัยความยินยอมที่คุณมอบให้กับเราเมื่อใดก็ได้ เพียงแค่ติดต่อเราตามที่ระบุในหัวข้อ “ติดต่อเรา” ด้านล่าง
หากคุณมีปัญหาใด ๆ กับการปฏิบัติตามระเบียบ คุณมีสิทธิที่จะยื่นคำร้องกับหน่วยงานกำกับดูแลของยุโรป 

6. การรักษาความปลอดภัยข้อมูล
เราใช้มาตรการรักษาความปลอดภัยที่สมเหตุสมผลและเหมาะสม ซึ่งออกแบบมาเพื่อคุ้มครองข้อมูลที่เรารวบรวมจากหรือเกี่ยวกับคุณ เพื่อป้องกันการเข้าถึง การใช้งาน การดัดแปลง การเปิดเผย หรือการทำลายที่ไม่ได้รับอนุญาต ข้อมูลจะถูกจัดเก็บไว้ จนกว่ามีคำขอให้ลบข้อมูลของบัญชีของผู้ใช้ที่จัดเก็บไว้ในเซิร์ฟเวอร์ของเราอย่างชัดเจน หรือจนกว่าหลักการทางกฎหมายสำหรับการประมวลผลข้อมูลไม่มีผลใช้งานอีกต่อไป อย่างไรก็ตาม โปรดทราบว่าไม่มีวิธีการส่งข้อมูลทางอินเทอร์เน็ตหรือการจัดเก็บข้อมูลใด ๆ ที่ปลอดภัยอย่างสมบูรณ์ ดังนั้น เราจึงไม่สามารถรับประกันถึงการรักษาความปลอดภัยของข้อมูลใด ๆ โดยสมบูรณ์ได้

7. การถ่ายโอนข้อมูลระหว่างประเทศ

เราตั้งอยู่ในสหรัฐอเมริกาและข้อมูลที่เรารวบรวมถูกกำกับดูแลโดยกฎหมายของสหรัฐอเมริกา ข้อมูลของคุณอาจถ่ายโอนไปยังและเก็บรักษาไว้ในคอมพิวเตอร์ที่ตั้งอยู่นอกรัฐ จังหวัด ประเทศ หรือเขตการปกครองของรัฐบาลอื่น ที่ซึ่งกฎหมายความเป็นส่วนตัวอาจไม่คุ้มครองข้อมูลได้เทียบเท่ากับกฎหมายในเขตการปกครองของคุณ หากคุณอยู่นอกสหรัฐอเมริกาและเลือกจะให้ข้อมูลกับเรา เราอาจถ่ายโอนข้อมูลดังกล่าวไปยังสหรัฐอเมริกา และเขตการปกครองอื่น ๆ และประมวลผลข้อมูลที่นั้น การใช้งานบริการใน Matrix On-Console หรือการให้ข้อมูลใด ๆ แสดงให้เห็นว่าคุณตกลงที่จะให้ถ่ายโอนและประมวลผลข้อมูล หากข้อมูลของคุณรวบรวมในยุโรป เราจะถ่ายโอนข้อมูลส่วนบุคคลของคุณโดยมีการป้องกันที่ถูกต้องหรือเหมาะสม เช่น ข้อสัญญาตามมาตรฐาน 


8. นโยบายของเราเกี่ยวกับเด็ก
บริการใน Matrix On-Console ไม่ได้มีไว้สำหรับผู้ที่มีอายุต่ำกว่า 13 ปี และเราไม่มีการรวบรวมข้อมูลส่วนบุคคลตามที่กำหนดโดยรัฐบัญญัติการคุ้มครองความเป็นส่วนตัวทางออนไลน์ของเด็ก ("COPPA") ของสหรัฐฯ จากเด็กอายุน้อยกว่า 13 ปีโดยเจตนา หากเราทราบว่าเรารวบรวมข้อมูลส่วนบุคคลของเด็กอายุต่ำกว่า 13 ปี เราจะดำเนินการลบข้อมูลดังกล่าวจากไฟล์ของเราโดยเร็วที่สุด

9. การเปลี่ยนแปลงนโยบายความเป็นส่วนตัวฉบับนี้

โปรดทราบว่านโยบายความเป็นส่วนตัวฉบับนี้อาจมีการเปลี่ยนแปลงเป็นครั้งคราว และคุณควรทบทวนนโยบายฉบับนี้เป็นระยะๆ ด้วย การเปลี่ยนแปลงใด ๆ จะมีผลทันทีเมื่อได้มีการประกาศนโยบายความเป็นส่วนตัวฉบับแก้ไข การใช้บริการของเราต่อบ่งบอกถึงความยินยอมของคุณต่อนโยบายความเป็นส่วนตัวที่ประกาศ หากมีการเปลี่ยนแปลงที่สำคัญ เราอาจมีการแจ้งเตือนคุณเพิ่มเติมทางที่อยู่อีเมลของคุณ

10. ผู้ควบคุมข้อมูล

กฎหมายคุ้มครองข้อมูลของสหภาพยุโรปแยกแยะระหว่างองค์กรที่ประมวลผลข้อมูลส่วนบุคคลเพื่อวัตถุประสงค์ของตนเอง (เรียกว่า “ผู้ควบคุม”) และองค์กรที่ประมวลผลข้อมูลในนามขององค์อื่น (เรียกว่า “ผู้ประมวลผล”) บริษัทอาจทำหน้าที่เป็นผู้ควบคุมหรือผู้ประมวลผลในส่วนที่เกี่ยวข้องกับข้อมูลส่วนบุคคลของคุณ ขึ้นอยู่กับสถานการณ์ บริษัทที่ตั้งอยู่ตามที่อยู่ในหัวข้อ “ติดต่อเรา” ด้านล่าง เป็นผู้ควบคุมข้อมูลที่คุณป้อนผ่านบริการใน Matrix On-Console ข้อมูลนี้ประกอบด้วยข้อมูลประจำตัวสำหรับการลงชื่อเข้าใช้ครั้งเดียว ข้อมูลผู้ใช้สำหรับ Asset Management และบริการอื่น ๆ

บริษัทที่ตั้งอยู่ตามที่อยู่ในหัวข้อ “ติดต่อเรา” ด้านล่าง เป็นผู้ประมวลผลข้อมูลการออกกำลังกายใด ๆ ที่สร้างขึ้นผ่านอุปกรณ์ฟิตเนส  ลูกค้าที่ซื้อบริการใน Matrix On-Console เพื่อมอบประสบการณ์ให้แก่ผู้ใช้ขั้นปลายของตนจะถือเป็นผู้ควบคุมข้อมูล  ในกรณีนี้ บริษัทจะเป็นผู้ประมวลผลข้อมูล ซึ่งประมวลผลข้อมูลผู้ใช้ตามความต้องการของลูกค้า

บางครั้ง บริษัทดำเนินการในฐานะผู้ประมวลผลในนามของลูกค้า ซึ่งเป็นนิติบุคคลที่แยกออกไปและเป็นผู้ควบคุม ตัวอย่างเช่น บริษัทจัดหาเทคโนโลยีให้แก่คลับและครูฝึก เพื่อมอบแอปและการติดตามฟิตเนสของพวกเขาเองให้แก่คุณ

ในกรณดังกล่าว บริษัทจะประมวลผลข้อมูลส่วนบุคคลในนามและตามคำสั่งของลูกค้า โปรดดูข้อมูลเกี่ยวกับหลักปฏิบัติด้านความเป็นส่วนตัวของพวกเขาได้ในนโยบายความเป็นส่วนตัวของลูกค้าที่เกี่ยวข้อง หากคุณมีคำถามใด ๆ เกี่ยวกับข้อมูลส่วนบุคคลดังกล่าว และสิทธิของคุณภายใต้กฎหมายการคุ้มครองข้อมูล คำถามดังกล่าวควรส่งไปให้แก่ลูกค้า เนื่องจากผู้ควบคุมข้อมูลไม่ใช่บริษัท
