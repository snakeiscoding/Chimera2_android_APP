# Module Interfaces

This module provides classes for common interfacing in our console software.<br>
For the main models that form our internal app API, see: [com.jht.interfaces.models]

# Package com.jht.enums

This package the enumerations used in the base models of the interfacing.

# Package com.jht.interfaces

This package contains the classes and interfaces that support the base models.

# Package com.jht.interfaces.models

This package defines the base models for our system interfacing. Mocks and implementations would extend these classes.<br>
**These are what would be injected into UI modules.**

# Package com.jht.mock

This package contains supporting classes for the testing mocks.

# Package com.jht.mock.interfaces

This package contains code for supporting testing mocks.

# Package com.jht.mock.interfaces.models

This package defines testing mock classes for the interfacing models.
